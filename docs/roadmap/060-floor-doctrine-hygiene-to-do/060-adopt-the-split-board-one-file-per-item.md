- [x] **Adopt the split board — one file per item, a generated index.** Done 2026-08-17. The monolithic
      `ROADMAP.md` (245 lines at the root) became `docs/roadmap/` — 7 sections, 28 item files, each carrying its
      checkbox line first and its detail beneath — with `docs/ROADMAP.md` as the index generated by atelier's
      `../atelier/tools/board.py`. The `board` floor check, already reaching this repo through the registry, was passing
      only because it found no `docs/roadmap/`; it is now genuinely in scope and enforced on both planes.
    - **Why, in this repo's terms.** The three defect classes behind atelier's ADR
      (2026-08-15) do not all bite here — this board was 245 lines, not 4,000, so read cost was not the
      motivation. What *did* apply: state asserted rather than derived (this board tracked state in prose glyphs
      — ✅ / ◑ / 🎯 — that no scanner could read), and contention at file grain (a single shared file for every
      session). An item's own `git log` is now its provenance.
    - **The one conversion that was not verbatim: the grammar.** Every top-level bullet here was `- **Title.**`
      with a ✅/◑ glyph *inside the prose*; none used the house checkbox grammar, so a purely mechanical split
      would have produced a board of zero items and an empty index (atelier's own cold pass recorded that class
      as BS3, where it hit 58 bullets). Each bullet was given a checkbox read off its own text — `[x]` only where
      nothing is outstanding, `[ ]` wherever a ◑, a "still owed" or an open sub-bullet remained — and the
      original glyphs were left standing in the body. Four items were given a bold title or a reflowed first line
      so the title closes on the state line, because the index projects the first physical line only.
    - **Continuations were re-indented 2 → 6 columns.** Words untouched. The house parser ends an item at any
      line indented under 4, so at 2 columns every body was invisible to `harvestscan`'s survivor search — the
      net that catches an item deleted with its work undone. This adds ~4 columns to board prose already over
      the house width; that debt is the wrapscan item above, not a new one.
    - **Residuals inherited from the parent, not introduced here** — atelier's board-store review cycle is
      **open** on BS1: at the hook plane, `board check` compares worktree to worktree, so a commit that stages an
      item edit without the rebuilt index still lands and is caught only by CI. Stage the item and the rebuilt
      index together. Rollout to this repo was Mike's explicit instruction (2026-08-17) ahead of that cycle
      closing; the gate was named at the time, not discovered after.
